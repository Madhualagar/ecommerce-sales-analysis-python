# E-Commerce Sales Data Analysis Using Python

## 📌 Project Overview

This project analyzes e-commerce sales data using Python to identify sales, profit, product, category, city, and monthly sales trends.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📊 Analysis Performed

- Data inspection and cleaning
- Missing-value analysis
- Product-wise sales analysis
- Category-wise sales and profit analysis
- City-wise sales analysis
- Monthly sales trend analysis
- Business KPI calculation
- Profit margin calculation
- Data visualization

## 📈 Key Metrics

- Total Sales
- Total Profit
- Total Quantity Sold
- Total Orders
- Average Order Value
- Overall Profit Margin

## 🎯 Objective

To practice Python-based data analysis and generate meaningful business insights from e-commerce sales data.

## 📂 Project File

`Ecommerce_Sales_Analysis.ipynb`
